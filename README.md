# 锚定杯方位标记系统（Orientation Anchor）

一个**单文件、零构建**的网页工具，用于在「2D 图像 → 3D 生成」流程中**锁定物体自身的绝对方位**，消除全局朝向歧义（左右镜像翻转、前后深度颠倒、上下方位错乱）。

工具提供一个可旋转的三维正交坐标架（锚定杯 / 人像两种载体），你把它旋转到与实物照片方位一致，即可生成模型能直接使用的**软约束（自然语言提示词）**和**硬约束（JSON）**。

---

## 解决的痛点

2D 转 3D 模型经常出现三类全局朝向错误：

- **左右镜像翻转**：物体的左被当成右
- **前后深度颠倒**：物体的正面/背面被互换
- **上下方位错乱**

本工具基于**伽利略相对运动等效原理**，用一个绝对坐标架锚定物体自身方位，把「方位真值」显式写进提示词与 JSON，供下游生成模型严格遵循。

---

## 功能特性

- **三维坐标架**：X = 左右、Y = 上下、Z = 前后，全部为**物体自身方位**
- **两种锚定载体**：锚定杯（左侧杯柄、正面图案）/ 人像，一键切换，逻辑一致
- **可见性渲染**：轴线可见部分为实线、被遮挡部分为虚线，随旋转实时更新
- **多种旋转方式**：三个滑杆分别控制 X / 上下、Y / 前后、Z 轴，或在 3D 视图中鼠标拖拽旋转，另有「复位（三轴归零）」
- **实物图比对**：上传参考照片，弹窗面板可自由拖动，便于与 3D 锚定物比对
- **前后左右浮标**：在参考图上点击打点并标注方向，点「确认」后锁定并随物体旋转，辅助用户定位物体前后左右
- **双模约束输出**：软约束（提示词）+ 硬约束（JSON），一键生成、复制即用

---

## 坐标语义（关键）

坐标架原点位于**物体的几何中心**，三条轴互相垂直：

| 轴 | 正值方向 | 负值方向 |
|----|----------|----------|
| X  | 物体自身**左**侧 | 物体自身**右**侧 |
| Y  | 物体自身**上**方 | 物体自身**下**方 |
| Z  | 物体自身**前**方 | 物体自身**后**方 |

> 三轴上标注的均为「物体自身上下前后左右」，与锚定杯、人像的自身方位完全一致。

## 使用步骤

1. 用浏览器打开 `index.html`
2. 点击右上角按钮选择**锚定杯**或**人像**
3. 在右侧「实物图上传」中上传实物照片，拖动面板与 3D 锚定物比对
4. 用滑杆或鼠标拖拽旋转，使锚定物方位与实物一致
5. （可选）点击「前 / 后 / 左 / 右」按钮，在参考图上打点，按「确认」锁定浮标
6. 点击「生成约束」，复制「软约束」或「硬约束」用于下游 2D 转 3D 模型

---

## 输出说明

- **软约束（提示词）**：用相机/自然语言描述「物体几何中心处的虚拟三维正交坐标架」，包含各轴正负对应的物体自身方位、当前欧拉旋转角、旋转后六方位的空间朝向向量，以及「禁止镜像 / 禁止深度颠倒 / 禁止上下错乱」的约束。
- **硬约束（JSON）**：结构化输出 `coordinate_frame_definition`、`euler_rotation_deg`、`object_orientation_vectors`、`constraints`、`anchor_object_type`，以及（若有）`confirmed_image_markers`。

> 两种约束**均不提及锚定杯本体**——因为 2D 转 3D 模型看不到锚定杯，只描述「物体中心想象的坐标架」。

## 本地运行

无需安装依赖，直接用现代浏览器打开 `index.html` 即可。也可用本地服务器：

```bash
python3 -m http.server 8000
# 然后访问 http://localhost:8000/
```

本仓库根目录即为 GitHub Pages 站点。启用方式：
